# Punjabi Wave — Sonic Atlas

Redesigned as a cinematic music discovery experience.

## What changed
- Minimal first screen with clear entry point
- Reduced HUD clutter
- Stronger visual hierarchy
- New cinematic typography and layout
- Live radio redesigned as a compact signal card
- Player redesigned around "Now in Orbit"
- Browse panel redesigned as a constellation index
- Mobile layout simplified
- Selected/playing stars receive stronger visual emphasis

## Run locally
```bash
python3 -m http.server 8080
```
Then open `http://localhost:8080`.
